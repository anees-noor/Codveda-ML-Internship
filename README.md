# Machine Learning Internship – Codveda Technologies

## About the Internship

This repository contains the projects and practical tasks completed as part of my **Machine Learning Internship at Codveda Technologies**.

The internship focuses on applying machine learning concepts through hands-on implementation using Python and its popular data science libraries.

**Internship Duration:** 26 October 2026 – 26 November 2026

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Tasks Completed

### Level 1 – Basic

**1. Data Preprocessing for Machine Learning**
- Handling missing values.
- Identifying numerical and categorical features.
- Encoding categorical variables.
- Feature standardization.
- Training and testing data splitting.

**2. Simple Linear Regression**
- Building a Linear Regression model.
- Understanding model coefficients.
- Predicting numerical values.
- Evaluating performance using Mean Squared Error (MSE) and R² score.

### Level 2 – Intermediate

**3. Decision Tree Classification**
- Training a Decision Tree classifier.
- Visualizing the decision tree.
- Understanding overfitting and tree depth.
- Evaluating accuracy and F1-score.
- Analyzing feature importance.

**4. Logistic Regression**
- Binary classification using customer churn data.
- Numerical feature scaling and categorical encoding.
- Model evaluation using accuracy, precision, recall, and F1-score.
- ROC curve and AUC analysis.
- Understanding coefficients and odds ratios.

### Level 3 – Advanced

**5. Random Forest Classification**
- Building an ensemble classification model.
- Hyperparameter tuning using GridSearchCV.
- Five-fold cross-validation.
- Evaluating classification performance.
- Feature importance analysis.

**6. Support Vector Machine (SVM) Classification**
- Implementing Linear and RBF kernels.
- Comparing different kernel performances.
- Evaluating classification metrics.
- ROC curve and AUC analysis.

## How to Run the Projects

1. Clone or download this repository.
2. Install the required libraries:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

3. Open the project folder.
4. Launch Jupyter Notebook:

```bash
jupyter notebook
```

5. Navigate to the required level and open the notebook.
